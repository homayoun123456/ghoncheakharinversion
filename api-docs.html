پارامترهای ورودی:

نامنوعتوضیحات

نمونه پاسخ:

GET /api/auth/me دریافت اطلاعات کاربر فعلی نیاز به توکن

هدرها:

Authorization: Bearer <token>

نمونه پاسخ:

{ "success": true, "user": { "id": 1, "username": "admin", "email": "admin@ghoncheye.com", "first_name": "ادمین", "last_name": "سیستم", "role": "administrator" } }

نامنوعتوضیحات

POST /api/posts ایجاد مطلب جدید نیاز به توکن

پارامترهای ورودی:

نامنوعتوضیحات
title *stringعنوان مطلب
contentstringمحتوای مطلب
excerptstringخلاصه
categorystringدسته‌بندی
statusstringوضعیت (draft, published)
featured_imagestringتصویر شاخص
PUT /api/posts/:id ویرایش مطلب نیاز به توکن

همان پارامترهای ایجاد، همه اختیاری

DELETE /api/posts/:id حذف مطلب نیاز به توکن

مطلب با شناسه مورد نظر حذف می‌شود.
